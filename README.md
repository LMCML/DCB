# 使用说明

使用该程序需要websocket连接NapCat服务器，需要DeepSeek的API Key。
管理员账号在QQ发送指令消息：'\`zs'为保存并关闭程序，'\`cd'为保存历史记录至本地，'\`hf'为强制立刻回复，'\`ys'为压缩本地历史记录。
